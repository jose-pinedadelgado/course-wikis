## Quick Start

```bash
cd database-management   # or any course folder
uv sync                  # install dependencies
uv run mkdocs serve      # serve at http://127.0.0.1:8000
```

### Prerequisites

- Python 3.12+
- [UV](https://docs.astral.sh/uv/) package manager
