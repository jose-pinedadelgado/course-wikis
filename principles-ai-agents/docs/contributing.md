# Contributing

This wiki was generated from *Principles of Building AI Agents* (2nd Ed.) by Sam Bhagwat as a teaching companion for Jose Pineda's courses at CSULB.

## Suggesting Changes

- Open an issue or pull request on the course-wikis repository
- Follow the existing formatting conventions (admonitions, collapsible sections, tables)

## Style Guide

- Use `!!!` admonitions for key concepts, tips, and warnings
- Use `???` for collapsible details and discussion questions
- Keep summaries concise — link to the book for full code examples
- Use tables for comparisons (providers, tools, tradeoffs)
