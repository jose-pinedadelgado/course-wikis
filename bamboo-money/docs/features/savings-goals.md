# Savings Goals

Track progress toward financial goals with visual progress bars.

## Creating a Goal

Each savings goal has:

- **Name** — e.g., "Emergency Fund", "Vacation", "New Car"
- **Target Amount** — How much you want to save
- **Current Amount** — How much you've saved so far
- **Target Date** — When you want to reach the goal

## Dashboard Widget

Goals appear as progress bars on the dashboard:

```
Emergency Fund     ████████████░░░░░░  $8,000 / $12,000  (67%)
                                        Target: June 2026

Vacation           ██████░░░░░░░░░░░░  $1,500 / $4,000   (38%)
                                        Target: Dec 2026
```

- Green bar when on track
- Yellow when behind pace
- Red when significantly behind
