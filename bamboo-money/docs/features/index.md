# Features Overview

Bamboo Money ships with 12+ features across budgeting, tracking, visualization, and AI assistance.

## Financial Core

- [**Dashboard**](dashboard.md) — Summary cards, spending donut, trends chart, budget progress bars
- [**Budgets & Rollover**](budgets.md) — Zero-based monthly budgets with automatic rollover
- [**Transactions**](transactions.md) — Full CRUD, search, filtering, and pagination
- [**Net Worth Tracker**](net-worth.md) — 34+ accounts, 5 groups, 8 metrics, historical charts
- [**Savings Goals**](savings-goals.md) — Visual progress bars with target dates and amounts

## Import & Export

- [**CSV Import & Export**](csv-import-export.md) — Auto-detect 10+ bank formats, smart dedup
- [**Excel Export**](excel-export.md) — Formatted .xlsx with 3 tabs (Dashboard, Tracker, Charts)

## Visualizations

- [**Sankey Cash Flow**](cashflow-sankey.md) — D3.js income flow diagram with month navigation
- [**Dark Mode & i18n**](dark-mode.md) — Full dark theme + English/Spanish translations

## Intelligence

- [**AI Chatbot**](chatbot.md) — GPT-4o-mini with inline charts, tables, and suggestions
- [**Recurring Detection**](recurring-detection.md) — Auto-detect subscriptions
- [**Categorization Rules**](categorization-rules.md) — Pattern-based auto-categorization
