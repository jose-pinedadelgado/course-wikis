# Data Drift

Data drift occurs when the distribution of input features changes over time after a model has been deployed. This can cause model performance to degrade.

---

## Covariate Drift

Covariate drift is a specific type of data drift where the distribution of one or more input features (covariates) changes between the training data and the production data.

## Jensen-Shannon Distance

Jensen-Shannon Distance is a method for measuring the similarity between two probability distributions. It's a symmetric and bounded version of KL divergence, making it useful for detecting distribution shifts.
