# Concept Drift

Concept drift occurs when the statistical relationship between input features and the target variable changes over time. Unlike data drift (which affects inputs), concept drift affects the **underlying patterns** the model learned.

---

## Kolmogorov-Smirnov Test

A statistical test that compares two distributions to determine if they are significantly different. Used to detect whether prediction distributions have shifted.
