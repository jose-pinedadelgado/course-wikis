# Confusion Matrix

A confusion matrix is used to evaluate the performance of a classification model. It compares actual values against predicted values, producing four key outcomes:

| | Predicted Positive | Predicted Negative |
|---|---|---|
| **Actual Positive** | True Positive (TP) | False Negative (FN) |
| **Actual Negative** | False Positive (FP) | True Negative (TN) |
