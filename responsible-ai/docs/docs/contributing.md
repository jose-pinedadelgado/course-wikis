# Contributing

Want to improve this wiki? Contributions are welcome!

## How to Contribute

1. **Fork** this repository on GitHub
2. **Create a branch** for your changes
3. **Edit or add** Markdown files in the `docs/` folder
4. **Submit a Pull Request** with a clear description of your changes

## What You Can Contribute

- Fix typos or unclear explanations
- Add examples or visualizations
- Improve code snippets
- Add new topics related to Responsible AI
- Translate content

## Guidelines

- Write in clear, accessible language
- Include Python code examples where applicable
- Use MathJax (`$$`) for mathematical formulas
- Follow the existing page structure: Concept → Formula → Code → Interpretation
- Test code examples before submitting

## Questions?

Open an issue on GitHub or reach out to the course instructor.
