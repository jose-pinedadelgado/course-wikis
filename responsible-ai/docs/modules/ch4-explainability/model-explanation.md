## Morris Sensitivity

Morris Sensitivity is a **global sensitivity technique**. It describes the impact that a feature has and how it would change the prediction, giving a high-level view of whether a feature has any effect on the model output.

This technique can help analysts:

- **Isolate** important features for further investigation
- **Discard** unimportant features for a less noisy model with a smaller feature space
