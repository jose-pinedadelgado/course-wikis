## Morris Sensitivity

Morris Sensitivity is a **global sensitivity technique** that describes the impact a feature has on model predictions and how changing it would alter the output.

This technique helps analysts:

- **Isolate features** for further investigation
- **Discard features** if doing so leads to a less noisy model with a smaller feature space

It provides a high-level view of whether a feature has any effect on the model output.
