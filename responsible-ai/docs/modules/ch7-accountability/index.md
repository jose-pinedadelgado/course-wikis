# Ch 7: Accountability in AI

Accountability in AI ensures that deployed models continue to perform fairly and accurately over time. The primary concern is **drift** — when the data or relationships in the data change after deployment.

## Types of Drift

- **[Data Drift](data-drift.md)** — Changes in the distribution of input features
- **[Concept Drift](concept-drift.md)** — Changes in the relationship between features and the target variable
